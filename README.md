# Home Finder

Real estate site: plain HTML, CSS and JS, no build step. Hosted on GitHub Pages.

- **Add or edit homes:** `data.js` (one block per home; photos live in `images/`, a full-size `name.webp` plus a `name-800.webp`).
- **Forms:** set `INBOX` at the top of `site.js` to the email address that should receive viewing, tour and valuation requests (sent via FormSubmit). While it's empty, forms run in preview mode.
- **Placeholders to replace:** phone number, email, the stats strip and testimonials on `index.html`.
